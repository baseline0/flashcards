Quick Start

# Install dependencies
uv sync

# Run tests
pytest tests/

# Start server
uvicorn src.flashcards.server.app:app --reload

Visit http://localhost:8000/docs for interactive API documentation.

Demo: Property & Casualty Insurance

The project includes a complete demo with 15 insurance terms. Load and study them:

POST /api/deck/load

Load glossary and generate cards

?domain=insurance&category=property&glossary_name=property_and_casualty
GET /api/deck/study

Get shuffled deck for studying

?domain=insurance&shuffle=true
POST /api/card/review

Record user review and update FSRS metrics

Project Structure

flashcards/
├── src/flashcards/
│   ├── core/          # Config, database setup
│   ├── domains/       # Pydantic schemas, SQLAlchemy models
│   ├── ingestion/     # Glossary parsers (JSON, Markdown, etc.)
│   ├── generators/    # Card synthesis engines
│   ├── srs/           # FSRS scheduler
│   ├── exporters/     # Output formats (Anki, JSON)
│   └── server/        # FastAPI app and routes
├── data/raw_glossaries/ # Glossary source files
├── tests/             # Unit tests (11 passing)
└── pyproject.toml     # Dependencies and config
