# ADR 0003: Keep or archive the CV learning governance document

**Status:** PROPOSED
**Date:** 2026-11-06
**Deciders:** Mark Alexiuk

## Context

`data/cv_learning/GOVERNANCE.md` is in the active tree. `TODO.md:24` records the open choice: archive or keep. The note says the file names no company. The repo already has an `archive/` directory.

## Options

1. Keep `data/cv_learning/GOVERNANCE.md` where it is.
2. Move it to `archive/` and leave the active tree without it.

## Owner question

Should `data/cv_learning/GOVERNANCE.md` stay in the active tree?

## Consequences

- Option 1: the governance rules stay in the active tree and need upkeep.
- Option 2: the file is kept for reference, and any link to it must be updated.
